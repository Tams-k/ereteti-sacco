1. Browser validation can be bypassed by users. Server-side validation provides another layer of security and ensures that only valid member numbers are accepted.

3. Deleting a record changes the database, so POST is used to avoid triggering deletion through a simple link. Edit uses a link to open the editing page and retrieve the existing record. Saving the changes then uses POST.

4. A prepared statement separates the SQL query from the values entered by the user. This means that user input is treated as data rather than executable SQL code.
